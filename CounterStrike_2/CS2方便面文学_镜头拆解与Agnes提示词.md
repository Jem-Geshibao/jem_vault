## 二、可迁移的视听逻辑提炼

### 2.1 叙事与节奏结构
- **三段式情绪曲线**：
  1. **轻快说教期**（0–6s）：多个人物用“吃面=见面”的谐音梗营造轻松、幽默、生活化氛围。
  2. **情绪转折期**（6–23s）：语气逐渐从“多吃/常见”滑向“少一桶/少一面”，用空镜与暗场制造下行落差。
  3. **升华收尾期**（23–30s）：由室内暗调宿舍切换至室外夜景，用“不是少一面，是多一面”完成情感反转与主题升华。
- **台词-画面绑定策略**：每个人物说一句谐音金句，画面以“吃面动作 + 对镜头说话”完成信息传递；字幕逐字出现，强化节奏点。
- **空间对比**：前 23 秒封闭、暖黄、人工光源的宿舍 ↔ 后 7 秒开放、冷蓝、自然夜景的阳台，形成情绪外化。

### 2.2 镜头语言可复用模式
- **机位循环**：固定近景胸像（主体占画面 40–50%）+ 同场景内快速横移换角 + 偶尔全景呼吸。
- **动作锚点**：所有人物统一执行“捧红色桶装面 → 叉子搅动/挑面 → 抬头对镜头说话 → 低头继续吃”的四拍循环，确保视觉连贯。
- **转场公式**：
  - 同场景人物切换 = 快速横移/甩镜头（保持空间连续性）。
  - 情绪段落切换 = 硬切到空镜/暗场（制造停顿）。
  - 空间/情绪升级 = 快速推进穿过遮挡物（窗帘/门框）+ 接室外大景。

### 2.3 光线与色彩风格
- **室内段**：低 key 暖光，主光源为桌面台灯（色温约 2700–3200K），背景压暗；人物肤色偏暖，墙面米黄，窗帘深蓝，形成冷暖对比。
- **室外段**：冷调夜景，城市光斑作为背景 bokeh，主光为月光/环境散射光（色温约 5600–6500K），人物面部保留柔和补光，情绪更沉静。
- **色彩锚点**：红色桶装面贯穿全片，作为视觉焦点与品牌/道具锚点。

### 2.4 表演与表情逻辑
- 前半段：表情偏生活化、略带夸张，嘴部动作配合字幕，制造“梗感”。
- 中段：表情逐渐收敛，语速放慢，眼神下垂。
- 结尾：正面凝视镜头，表情由凝重转为释然，嘴唇微张，制造“金句定格”效果。

### 2.5 音频（源文件无音频，以下为根据画面反推的推测）
- **音乐**：推测为情绪递进的中文抒情/说唱 beat，前段轻快、中段加入钢琴或弦乐下行、尾段情绪上扬。
- **音效**：吃面声、叉子碰桶声、宿舍环境底噪、阳台夜晚风声/城市远噪。
- **人声**：每位人物以中文念白方式说出谐音台词，语速由快到慢。

## 四、精简禁止项（Negative Prompt / Do-Not List）

为避免生成结果出现人物变脸、服装/道具漂移、肢体错误、背景闪烁、动作断裂、光影跳变及物理关系失真，请在 Agnes Video 2.5 生成时加入以下约束：

```
Do not include: face morphing, identity shifting between shots, costume or jersey logo changes within a continuous scene, floating noodle cup or fork, disembodied hands, extra fingers, twisted limbs, backward hands, inconsistent hairstyle between shots, background flicker, light source jumping between frames, shadow direction inconsistency, physics-defying noodles or liquid, abrupt camera jitter, motion blur on static faces, duplicated characters in reflection, brand names or copyrighted logos, text overlays unless specified.
```

### 按风险类型细分

| 风险类型 | 禁止项 | 检查方法 |
|---|---|---|
| **人物一致性** | 同一人镜头间脸型/发型/五官突变；不同人物混脸；表情不连续 | 逐镜对比额头、发际线、眉骨 |
| **服装/道具锚定** | 红色桶装面杯消失、变色、变形；队服赞助商 logo 漂移；叉子位置跳变 | 确认每镜都有红色面杯，且队服款式与镜头匹配 |
| **肢体正确性** | 多指、断指、反关节、手腕翻转错误、捧杯手势不自然 | 重点检查手部与面杯的接触关系 |
| **背景稳定性** | 窗帘/书架/台灯位置跳变；窗外城市灯光闪烁 | 同场景内背景元素保持空间一致 |
| **光影连续性** | 主光源方向突然改变；肤色色温跨镜漂移；同镜头内明暗跳变 | 记录每镜主光方向与色温 |
| **动作连贯性** | 吃面动作中间帧缺失；说话口型与情绪脱节；镜头运动卡顿 | 检查相邻帧人物姿态自然过渡 |
| **物理关系** | 面条悬空、叉子穿透杯壁、人物与桌面穿模 | 检查道具与人物的接触面 |

## 六、执行建议

1. **先按单人物生成**：将 4 位主要说话者分别作为独立角色参考生成，避免 AI 把多个人物混淆成同一张脸。
2. **固定道具 LORA / Reference**：提前准备一张“红色桶装牛肉面”参考图，确保每镜桶身颜色、大小、标签位置一致。
3. **分镜渲染后剪辑**：Agnes Video 2.5 单段生成 5s 左右为宜，30s 全片建议拆成 10 镜分别生成，再在剪辑软件中按本时间轴硬切/甩镜拼接。
4. **字幕后加**：画面内中文字幕建议在后期添加，避免模型生成乱码或不该出现的文字。
5. **音频后配**：源片无音频，建议在剪辑阶段加入情绪递进的中文抒情 beat + 吃面/环境音效 + 念白。
