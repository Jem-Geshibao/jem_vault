# jem_vault 📚

Shared Knowledge Note Repository

## 📋 Project Introduction

This project aims to build a shared, open, and continuously growing knowledge note repository. Anyone can contribute study notes, experience summaries, ideas, technical materials, and other content here. Using GitHub for version control and sharing helps everyone turn scattered knowledge into lasting, reusable knowledge assets.

## 🎯 Repository Goals

- Build a large shared knowledge note library
- Make every note easy to save, view, and discuss
- Prevent local notes from being lost through cloud synchronization
- Encourage everyone to learn and improve together

## 📝 How to Contribute

### 1. Manual Submission

You can directly add your own note files to the repository, then commit and push them.

### 2. Automatic Sync with Obsidian + Git Plugin

You may also clone this repository locally and use the Git plugin in Obsidian for automatic synchronization. This allows notes to be synced to the repository as you record and organize them, making long-term storage and sharing easier.

## 📁 Repository Content

This repository is suitable for storing:

- Study notes
- Reading notes
- Technical notes
- Work summaries
- Ideas and inspiration
- Resource organization

## 🧭 Usage Tips

- Back up and update notes regularly
- Use clear and consistent file naming
- Keep the structure organized for easier future reference
- Contributions and continuous improvements are always welcome

## 📄 Notes

The core philosophy of this repository is:

- Let knowledge be captured and retained
- Keep notes stored long-term
- Enable more people to share and grow together

If you encounter issues while using notes, organizing content, or syncing via the Obsidian Git plugin, please submit an issue in the Issues section. We will work together to help resolve it.

Everyone is welcome to participate and help build a more complete, practical, and continuously growing knowledge note repository.
